## 3. Cross-Validation Execution Sequence

### 3.1 Outer Split Reuse
To ensure complete mathematical comparability with the Stage 3B.2 baseline, Stage 3B.3 **must reuse the identical outer folds** generated by `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)` and saved in `ml_lab/experiments/stage_3b_2/fold_assignments.csv`.

### 3.2 Iterative Fold Loop
For each fold $k \in \{0, 1, 2, 3, 4\}$:
1. Extract training indices `train_idx` ($N \approx 18,972$) and validation indices `val_idx` ($N \approx 4,743$).
2. Verify zero group overlap: $\text{groups}(\text{train\_idx}) \cap \text{groups}(\text{val\_idx}) = \emptyset$.
3. For each candidate model $M \in \{\text{LogisticRegression}, \text{RandomForest}, \text{XGBoost}\}$:
   - Construct fresh, uninitialized pipeline instance.
   - Start wall-clock timer (`time.perf_counter()`) and memory trace (`tracemalloc.start()`).
   - Fit pipeline strictly on `(X_train, y_train)`:
     - Numerical median imputer and scaler compute statistics **exclusively** on `X_train`.
     - Categorical most-frequent imputer and one-hot encoder compute categories **exclusively** on `X_train`.
     - Estimator fits weights/trees **exclusively** on transformed `X_train`.
   - Record training duration ($\Delta t_{\text{train}}$) and peak heap memory ($\Delta M_{\text{peak}}$).
   - Generate validation predicted probabilities $\hat{p}_{\text{val}} = \text{predict\_proba}(X_{\text{val}})[:, 1]$.
   - Generate discrete binary predictions $\hat{y}_{\text{val}} = \mathbb{I}(\hat{p}_{\text{val}} \ge 0.50)$.
   - Store predictions in fold accumulator and out-of-fold array.
   - Compute fold-level metrics.

## 4. Evaluation Metrics Specification

All models will be evaluated using strictly pre-defined, standardized metrics implemented in `ml_lab/evaluation/metrics.py`:

| Metric Name | Mathematical Definition | Evaluation Focus |
|---|---|---|
| **ROC-AUC (Primary)** | $\text{AUC} = \frac{\sum_{i \in \text{pos}} \sum_{j \in \text{neg}} \mathbb{I}(p_i > p_j) + \frac{1}{2}\mathbb{I}(p_i = p_j)}{N_{\text{pos}} \times N_{\text{neg}}}$ | Threshold-independent discrimination power across the full operational range. |
| **Brier Score (Primary Calibration)** | $\text{Brier} = \frac{1}{N} \sum_{i=1}^N (p_i - y_i)^2$ | Strict mean squared error of predicted probabilities against binary ground truth. |
| **Expected Calibration Error (ECE)** | $\text{ECE} = \sum_{m=1}^{10} \frac{|B_m|}{N} |\bar{p}(B_m) - \bar{y}(B_m)|$ | Decile-stratified alignment between predicted confidence and empirical positive prevalence. |
| **Accuracy ($\tau=0.50$)** | $\frac{TP + TN}{N}$ | Overall discrete classification accuracy at default threshold. |
| **Balanced Accuracy** | $\frac{1}{2} \left( \frac{TP}{TP + FN} + \frac{TN}{TN + FP} \right)$ | Arithmetic mean of sensitivity and specificity, correcting for class imbalance. |
| **Precision** | $\frac{TP}{TP + FP}$ | Positive predictive value. |
| **Recall (Sensitivity)** | $\frac{TP}{TP + FN}$ | True positive detection rate. |
| **Specificity** | $\frac{TN}{TN + FP}$ | True negative detection rate. |
| **F1 Score** | $\frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$ | Harmonic mean of precision and recall. |
| **Confusion Matrix** | $\begin{bmatrix} TN & FP \\ FN & TP \end{bmatrix}$ | Complete 2x2 error distribution matrix. |
| **Fold-Level Stability** | $\mu_{\text{fold}} \pm \sigma_{\text{fold}}$ across folds $0 \dots 4$ | Assessment of cross-validation variance and fold stability. |

## 5. Runtime and Hardware Measurement Methodology

To ensure scientific reproducibility, computational performance will be logged with rigorous distinction between measured values and theoretical estimates:

1. **Measured Wall-Clock Latency:**
   - Tool: Python standard library `time.perf_counter()`.
   - Granularity: Measured separately for (a) inside-fold training, (b) inside-fold validation inference, and (c) overall pipeline execution.
2. **Measured Heap Memory Allocation:**
   - Tool: Python standard library `tracemalloc`.
   - Metric: Peak memory delta `tracemalloc.get_traced_memory()[1]`, capturing peak Python heap memory allocated during fitting and transformation.
3. **Environment Metadata:**
   - Logged at runtime: OS platform, CPU architecture, core count, Python version, scikit-learn version, and xgboost version.
4. **Distinction from Estimates:**
   - Any asymptotic complexity notations (e.g., $\mathcal{O}(T \cdot N \log N \cdot p)$) are explicitly labeled as theoretical algorithmic complexity estimates, distinct from empirical wall-clock runtimes.
